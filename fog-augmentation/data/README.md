# Data

All datasets live here (not committed to git). They must be obtained manually.

---

## 1. Cityscapes

**Requires free account at** https://www.cityscapes-dataset.com/

Download the following packages via the website or `csDownload`:

| Package | Approx. size | Contents |
|---|---|---|
| `leftImg8bit_trainvaltest.zip` | 11 GB | Main RGB images |
| `leftImg8bit_trainextra.zip` | 44 GB | Extra coarse images (optional) |
| `gtFine_trainvaltest.zip` | 241 MB | Fine annotations (19 classes) |
| `disparity_trainvaltest.zip` | 3.6 GB | Stereo disparity maps |
| `camera_trainvaltest.zip` | 1.9 MB | Camera calibration JSON |
| `rightImg8bit_trainvaltest.zip` | 11 GB | Right stereo images (optional) |

Extract all into `data/cityscapes/` so the layout is:
```
data/cityscapes/
  leftImg8bit/{train,val,test}/<city>/*_leftImg8bit.png
  gtFine/{train,val}/<city>/*_gtFine_labelTrainIds.png
  disparity/{train,val}/<city>/*_disparity.png
  camera/{train,val}/<city>/*_camera.json
```

---

## 2. ACDC (fog split)  — evaluation only

**Requires free account at** https://acdc.vision.ee.ethz.ch/

Download the ACDC dataset and extract so the layout is:
```
data/acdc/
  rgb_anon/fog/{train,val,test}/<sequence>/*_rgb_anon.png
  gt/fog/{train,val}/<sequence>/*_gt_labelTrainIds.png
```

**IMPORTANT: never train on ACDC data. It is used for evaluation only.**

---

## 3. Foggy Cityscapes (optional depth-aware baseline)

Available through your Cityscapes account at the Cityscapes website.  
Download `leftImg8bit_foggy_beta_*.zip` and extract to `data/foggy_cityscapes/`.

---

## 4. Pre-rendered fog cache

Generated by `scripts/generate_fog.py`.  
Stored under `data/fog_cache/{photometric,depth_aware}/<variant>/`.  
Can be regenerated at any time; not committed to git.

---

## Symlinks (alternative)

If datasets live on a shared NFS mount, you can symlink:
```bash
ln -s /mnt/shared/cityscapes  data/cityscapes
ln -s /mnt/shared/acdc        data/acdc
```
